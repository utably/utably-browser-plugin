Privacy and Data Use

Utably Import is designed for user-controlled imports. We only collect and send data when you explicitly click Save to Utably.

  • User-initiated only: no background crawling across websites.
  • Review-first flow: extracted fields are shown for editing before submit.
  • Minimal permissions: host access is requested per site only when Auto-fill is used.
  • No credential capture: extension does not read your passwords.
  • LinkedIn mode: manual description entry by design.
  • Authentication uses short-lived extension tokens and revocable sessions.

Data policy last updated: February 19, 2026. For full legal terms and data rights, visit Utably legal pages in the selected stage.
